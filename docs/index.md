# DevMap Pipeline

DevMap Pipeline is a personal tool used by Ege Doğan to produce short educational technology videos and upload them to his own YouTube channel, DevMap TR.

It runs only on the owner's own computer. It uses the YouTube Data API solely to upload videos that the owner has reviewed and approved. It is not offered to other users.
