# DevMap Pipeline - Privacy Policy

Last updated: October 24, 2026

DevMap Pipeline is a personal tool operated by Ege Doğan. It is used only by its owner to upload videos to his own YouTube channel. It is not offered to the public.

## What data is accessed

The tool requests a single Google permission: https://www.googleapis.com/auth/youtube.upload. It uses this permission only to upload videos, with their titles, descriptions and tags, to the authorized YouTube channel. It does not read, modify or delete any other YouTube or Google account data.

## How data is stored

The access token created during authorization is stored only on the owner's own computer, in a local file that is never shared or uploaded anywhere. No user data is collected, sold, shared with third parties, or used for advertising.

## YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service (https://www.youtube.com/t/terms). Google's handling of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the local token file also removes the tool's access.
